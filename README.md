# Fethiye Emlak

Fethiye ve çevresindeki satılık ve kiralık konutları tanıtmak için hazırlanmış, Türkçe ve mobil uyumlu statik emlak sitesi.

## Yerel olarak görüntüleme

https://egerzz.github.io/fethiye-emlak/


## Proje yapısı

- index.html — sayfa içeriği
- assets/css/style.css — görünüm ve duyarlı düzen
- assets/js/script.js — gezinme, ilan arama, favoriler ve ilan detay penceresi
- assets/images/ — site görselleri
- favicon.svg — tarayıcı sekmesi simgesi
